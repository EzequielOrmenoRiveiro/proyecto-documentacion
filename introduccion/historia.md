# Historia del desarrollo web

## Inicio del desarrollo web

El desarrollo web comenzó en 1989, cuando Tim Berners-Lee creó la World Wide Web (WWW).
En 1991 se publicó la primera página web. Era muy sencilla y servía para compartir información mediante Internet.

## Evolución de las páginas web

Con el paso de los años, las páginas web fueron mejorando:

- **Años 90:** las páginas eran sencillas y tenían principalmente texto y enlaces.
- **Años 2000:** empezaron a aparecer páginas más visuales y dinámicas.
- **Años 2010:** aumentó el uso de móviles y las páginas se adaptaron a diferentes pantallas.
- **Actualidad:** existen páginas interactivas, tiendas online, redes sociales y aplicaciones web.

## Importancia del desarrollo web

Hoy en día, el desarrollo web es muy importante porque permite comunicarnos, estudiar, trabajar, comprar y acceder a información desde cualquier lugar.
