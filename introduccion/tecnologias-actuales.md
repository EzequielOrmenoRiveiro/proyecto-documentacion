# Tecnologías actuales del desarrollo web

## HTML

HTML se utiliza para crear la estructura de una página web. Por ejemplo, permite añadir títulos, textos, imágenes y enlaces.

## CSS

CSS sirve para dar estilo a las páginas web, como los colores, tamaños, fondos y tipos de letra.

## JavaScript

JavaScript permite que las páginas web sean interactivas. Por ejemplo, permite crear botones que realizan acciones.

## Otras tecnologías

También existen otras herramientas que se utilizan actualmente:

- **React:** sirve para crear interfaces de usuario.
- **Angular:** permite desarrollar aplicaciones web.
- **Node.js:** permite utilizar JavaScript en el servidor.
