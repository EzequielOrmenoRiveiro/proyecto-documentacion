##¿Qué es el desarrollo web?

#Definición

El desarrollo web consiste en crear páginas y aplicaciones que podemos utilizar a través de Internet.

Por ejemplo, cuando entramos en una tienda online, una red social o una página de noticias, estamos utilizando una web que ha sido desarrollada por alguien.

Partes del desarrollo web

El desarrollo web se divide principalmente en dos partes:

**Frontend:** Es la parte visual de una página web, es decir, todo lo que vemos y con lo que podemos interactuar.
**Backend:** Es la parte que funciona por detrás y se encarga de procesar los datos y hacer que la página funcione correctamente.

#Tecnologías utilizadas

Algunas de las tecnologías más conocidas son:

- HTML: sirve para crear la estructura de una página.
- CSS: se utiliza para darle diseño y color.
- JavaScript: permite añadir funciones e interactividad.
