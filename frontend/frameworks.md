\# Frameworks de desarrollo web



\## ¿Qué es un framework?



Un framework es un conjunto de herramientas, bibliotecas y estructuras que facilitan el desarrollo de aplicaciones web. Permite reutilizar código y organizar mejor los proyectos.



\## Frameworks de frontend



Se utilizan para desarrollar la parte visual de una página web, es decir, aquello con lo que interactúa el usuario.



\- \*\*Angular:\*\* framework desarrollado por Google que permite crear aplicaciones web dinámicas.

\- \*\*Vue.js:\*\* framework progresivo que facilita la creación de interfaces de usuario.

\- \*\*React:\*\* biblioteca de JavaScript desarrollada por Meta para crear interfaces interactivas.



\## Frameworks de backend



Se utilizan para desarrollar la parte interna de las aplicaciones, gestionar datos y procesar las peticiones de los usuarios.



\- \*\*Express.js:\*\* framework de Node.js utilizado para crear servidores y API.

\- \*\*Django:\*\* framework de Python que facilita el desarrollo de aplicaciones web.

\- \*\*Spring:\*\* framework de Java utilizado para crear aplicaciones y servicios web.



\## Ventajas de utilizar frameworks



\- Permiten ahorrar tiempo de desarrollo.

\- Facilitan la organización del código.

\- Favorecen la reutilización de componentes.

\- Ayudan a mantener proyectos grandes.

\- Proporcionan herramientas y estructuras ya preparadas.
