\# Frameworks de desarrollo web



\## ¿Qué es un framework?



Un framework es un conjunto de herramientas y estructuras que facilita el desarrollo de aplicaciones mediante componentes y funcionalidades reutilizables.



\## Frameworks frontend



\- React: biblioteca para crear interfaces de usuario.

\- Angular: framework basado en TypeScript.

\- Vue.js: framework progresivo para interfaces web.



\## Frameworks backend



\- Express: framework para aplicaciones Node.js.

\- Django: framework web basado en Python.

\- Spring: framework para aplicaciones Java.



\## Ventajas



\- Reutilización de código.

\- Organización del proyecto.

\- Mayor productividad.

\- Facilita el mantenimiento.
