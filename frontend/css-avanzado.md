\# CSS avanzado



\## ¿Qué es CSS?



CSS (Cascading Style Sheets) es el lenguaje utilizado para definir la presentación visual de los documentos HTML.



\## Selectores



Permiten seleccionar los elementos que queremos modificar.



\- Selectores de etiqueta.

\- Selectores de clase.

\- Selectores de identificador.



\## Diseño avanzado



CSS ofrece diferentes herramientas:



\- Flexbox: distribución de elementos en una dimensión.

\- Grid: organización en filas y columnas.

\- Media Queries: adaptación a diferentes pantallas.

\- Animaciones y transiciones.



\## Variables CSS



Permiten almacenar valores reutilizables mediante la propiedad `--nombre`.
