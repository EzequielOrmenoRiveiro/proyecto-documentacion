\# HTML básico\## ¿Qué es HTML?HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para estructurar el contenido de las páginas web.\## Estructura básicaUn documento HTML contiene los siguientes elementos:\- `<!DOCTYPE html>`: indica la versión HTML5.\- `<html>`: elemento principal.\- `<head>`: contiene información del documento.\- `<body>`: contiene el contenido visible.\## Elementos principales\- `<h1>`: encabezado principal.\- `<p>`: párrafo.\- `<a>`: enlace.\- `<img>`: imagen.\- `<ul>` y `<li>`: listas.\## FormulariosHTML permite crear formularios mediante elementos como `<form>`, `<input>` y `<button>`.\## Más información\[Documentación oficial de HTML - MDN](https://developer.mozilla.org/es/docs/Web/HTML)
