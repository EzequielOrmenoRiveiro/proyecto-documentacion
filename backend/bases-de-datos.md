\# Bases de datos



\## ¿Qué es una base de datos?



Una base de datos es un sistema organizado que permite almacenar, consultar, modificar y gestionar información.



\## Tipos de bases de datos



\- \*\*Relacionales:\*\* organizan la información en tablas relacionadas entre sí.

\- \*\*No relacionales:\*\* almacenan información mediante estructuras diferentes a las tablas tradicionales.



\## Ejemplos



\- \*\*MySQL:\*\* sistema de gestión de bases de datos relacional.

\- \*\*PostgreSQL:\*\* sistema relacional de código abierto.

\- \*\*MongoDB:\*\* base de datos no relacional orientada a documentos.

\- \*\*SQLite:\*\* base de datos relacional ligera.



\## Importancia en el desarrollo web



Las bases de datos permiten almacenar usuarios, productos, publicaciones y otros datos necesarios para el funcionamiento de una aplicación.
