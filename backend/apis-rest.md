\# APIs REST



\## ¿Qué es una API?



Una API es una interfaz que permite que diferentes aplicaciones se comuniquen e intercambien información.



\## ¿Qué es REST?



REST es un estilo de arquitectura utilizado para diseñar servicios web que permiten acceder y gestionar recursos mediante peticiones HTTP.



\## Métodos HTTP principales



\- \*\*GET:\*\* obtener información.

\- \*\*POST:\*\* crear información nueva.

\- \*\*PUT:\*\* actualizar un recurso.

\- \*\*DELETE:\*\* eliminar un recurso.



\## Funcionamiento



Una aplicación envía una petición a una dirección del servidor. La API procesa la petición y devuelve una respuesta, normalmente en formato JSON.



\## Importancia



Las APIs permiten conectar aplicaciones, compartir información e integrar servicios externos.
