\# Servidores web



\## ¿Qué es un servidor web?



Un servidor web es un sistema que recibe peticiones de los clientes y envía los recursos necesarios para mostrar una página web.



\## Funcionamiento



1\. El usuario introduce una dirección web en el navegador.

2\. El navegador envía una petición al servidor.

3\. El servidor procesa la petición.

4\. El servidor devuelve una respuesta al navegador.



\## Tipos de servidores



\- \*\*Apache:\*\* servidor web de código abierto muy utilizado.

\- \*\*Nginx:\*\* servidor conocido por su rendimiento y capacidad para gestionar muchas conexiones.

\- \*\*IIS:\*\* servidor web desarrollado por Microsoft.



\## Importancia



Los servidores permiten alojar páginas web y hacer que estén disponibles para los usuarios a través de Internet.
